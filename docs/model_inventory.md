定义：MSE=mean((p−y)²)，MAE=mean(|p−y|)，variance QLIKE=mean((y/p)²−log((y/p)²)−1)。同日相邻实际时间差0–90秒才计路径链接，午休/日切换不计。跳变为|p(t)−p(t−1)| / max((v(t)+v(t−1))/2,1e−8)超过Train确定的逐标的阈值；v为当前观测Rvol1D，不是未来y。毛刺为上述跳变后10分钟内反向回撤至少初始变动50%，分母同为全部合格链接。它是回顾性路径诊断，不可实时当作已知信号。

阈值沿用原run的shared_relative_threshold，不重新在Test选择。evaluation.evaluate要求显式传入Train阈值；权重包fit_audit.threshold为原初始化阶段阈值，不能未经原定义核对直接冒充所有报告的阈值。

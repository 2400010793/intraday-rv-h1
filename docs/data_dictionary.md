# 生产输入与特征定义

唯一推理入口为一个标的当前时点的生产行。`y_true`、`target_datetime`、`predRVol1D`不是输入；额外字段在接口边界丢弃。H1是下一交易日相同物理clock的年化波动率，不能用日级目标广播。

| 必需字段 | 类型、单位 | 可用时间要求 | 缺失行为 |
|---|---|---|---|
| usymbol | string：IF/IH/IC/IM/159915/588000 | 当前 | 缺失/标的不符报错 |
| trade_date | YYYY-MM-DD，上海交易日 | 当前 | 缺失/与datetime不符报错 |
| datetime | 无时区的上海物理时间，保留秒 | 当前；不得先读下一行 | 重复相同内容幂等；冲突或乱序报错 |
| ret | float，生产连续对数收益，小数单位 | 当前行已发布 | 显式缺失，滚动支持不完整时标记/屏蔽；不能以spotRef推算替代生产连续期货收益 |
| ttime | float，生产方差时间累计坐标 | 当前行已发布 | 非有限直接报错；差分非正不能用于年化 |
| spotRef | float，生产参考价格，点或元 | 当前行已发布 | 价格状态失效，重建新段；不跨缺失段比较价格 |
| rvol1D | float，年化波动率，0.12表示12% | 当前行已发布 | 核心特征延续同clock历史有效值并标记 |
| rvol1hour | float，年化波动率，小数 | 当前行已发布 | 同clock历史辅助特征延续并标记 |

字段必须存在，但允许上述指定的显式null。无合法历史则失败。无穷数、非正价格/RV直接拒绝。数据库另下载rvol15min、rvol3D供核对，模型不消费这两列。没有字段级历史发布时间与修订轨迹；本实现不能证明数据库快照等于当时生产发布值。ttime上游ETL没有被本仓库重建。

## 核心输入和精确边界

令r为生产ret，v为rvol1D，a为生产ttime；年化常数260。剔除每个交易日首物理行收益，使用最近期货242/ETF239个日内观测：

- N=260 Σr²1(r<0)，P=260 Σr²1(r>0)。15:00按当日累计计算，保持原实现。
- 三核心通道为log(v²)、log(N)、log[1+(P−N)/v²]。
- 每个已注册clock保存最近80个原来有效的三核心观测。缺失延续值不写成新的原有效历史，避免改变已有模型的窗口语义。缺失收益不会被当作零收益；受影响半变差窗口不可用并显式延续历史值。
- 初始拍卖行原模型没有训练，因此用此前已完成半变差和当前已知RV，注册表映射首个已训练clock。缺少前缀时延续该clock历史辅助值，输出opening标记；不读取今天后续时点。

原研究保留负半变差数值通道及短期百分位；negative80百分位交叉已删除，不等于删除负半变差本身。

## 15/30三时点动态通道（原ONDS位置）

对w∈{15,30}，R(w,t)=Σ(i=0..w−1)r(t−i)，D(w,t)=Σ(i=0..w−1)[a(t−i)−a(t−i−1)]，差分必须为正。分支σ(w,t)=clip(sqrt(260R²/D),0.08,1)。

先分别合并当前、前1行、前2行：S(w,t)=clip(sqrt[Σ(k=0..2)D(w,t−k)σ(w,t−k)²/Σ(k=0..2)D(w,t−k)],0.08,1)。这是物理观测行，不是在午休处凭空插入分钟。

再令b=[(S15+0.05)/(S15+S30+0.1)]²，通道为log[(b S15+(1−b)S30)²]。这个通道含义是短窗累计收益的年化幅度，不能称为纯隔夜跳动代理。

第二替代通道是原生DS15：分支长度15/60，分支年化先截[0.05,1]，随后最近15行按对应ttime跨度加权平方平均、开方截[0.08,1]，最后相同fast/slow混合。每日首行ret置0。

## 其他输入

1H辅助为log(rvol1hour²)。5/15开盘前缀：每日首行ret置0，各分支以5/15行收益和及对应ttime跨度年化、截[0.05,1]；从本日第一个常规观测起，累积能量σ²D与D后取比值，波动率截[0.08,1]；分别使用fast和slow方差的log。重建前缀的第六辅助槽已关闭，运行代码明确置零。冻结aux_enabled决定哪些clock可用。

百分位使用包内冻结ECDF，q=(小于x的数量+0.5×等于x的数量+0.5)/(n+1)，状态包括2q−1及其高尾折线max(2q−1−0.6,0)/0.4。输入顺序、标准化、Ridge、卷积、attention初值/边界及非持久化分位张量全部从已有资产移植，不重估。

收益token仅使用：期货开盘15分钟收益，ETF当日首笔隔夜收益。前者以第一常规观测为锚，只在之后完整15分钟支持成熟后发布；不提前广播日内终值。两者分位参考仅此前已完成交易日。价格20日分位以此前已完成收盘为参考：期货使用生产ret连续路径，ETF使用spotRef；不包括今天收盘。其他未被forward消费的收益槽是中性值。

calendar包括当日星期、前一交易日至当前的自然日/工作日间隔log1p及常数；时间、分组ID和物理位置来自冻结clock注册表。clock键HH:MM__occurrence保留同分钟不同秒观测。缺失非首时点不自动生成伪记录。

## 数值延拓与平滑

默认carry延续同clock历史有限特征。候选在x≥ε保留log(x)，在x<ε用log(ε)+(x−ε)/ε或log(ε)+asinh((x−ε)/ε)。ε来自截至2026-08-03 09:30:10正值的0.1%分位。两个候选在连接点函数值与一阶导数连续，但尚未通过MSE、QLIKE、毛刺三指标不劣检验，不能在生产启用。

平滑输出s(t)=0.75p(t)+0.25s(t−1)，固定半衰期0.5观测行，无有限长度硬截断；残余权重按0.25^k递减。日切换、午休及间隔>90秒重置。它是既有平滑口径，不在Test重新选参数。
